What you use it for

  • Add, edit, and delete rules

    The panel is the rule book. Start from the APA 7 preset or a set you write, then change or remove a rule when the brief changes. Nothing on this screen rewrites a document.

  • Detailed enough to pass a layout check

    Spell out the spacing, headings, and citations a check actually looks for. The assistant then makes those edits, instead of guessing a vague style.

  • APA 7, or a house style

    One included preset is APA 7 for a thesis or dissertation, including when you already write in Word. Edit it for a school's or advisor's house style. It is not a Microsoft add-in, and it is not the only set the panel is for.

  • Apply and review outside the panel

    Use a chat command, or have Claude Code or a script read the panel rules. Execute asks the assistant to apply the edits. Check only lists gaps. The panel has no Check or Execute button.

The panel only stores and manages your rules. Checking a document and applying fixes happens in chat, or when Claude Code or a script reads the rules you kept. Check only lists gaps. It does not silently rewrite the chapter. The panel does not open Word and does not accept a .docx. Any change to a file is made by your own assistant. We never receive your .docx.

How a session goes

  1. Keep your rules. Install the panel, then add, edit, or delete rules. The APA 7 preset is only a starting point.
  2. Execute, in chat. Ask your own AI assistant — or Claude Code, or a script that reads the panel — to apply those rules to your file.
  3. Check, in chat. Ask it to run Check. You get a list of gaps. Check only lists gaps and does not silently rewrite the chapter.
