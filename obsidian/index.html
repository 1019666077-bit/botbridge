How it fits

  1. Install the thin Cursor plugin when available (or clone obsidian-bridge-plugin).
  2. Point the local Obsidian MCP at your vault folder path.
  3. Ask Cursor to read a note, append a work log, or search — it stays on your disk.
No cloud vault sync through us. If the path is wrong or Obsidian isn’t set up, tools will fail until you fix the local config.
