Webcam Bridge

Give Cursor one on-demand webcam frame in the current chat. The free thin plugin is the Marketplace front door; real capture is a local MCP server that opens the camera, returns one JPEG, and releases the device.

免费薄插件做引流；真正抓拍是本机 MCP（webcam_mcp）：按需开摄像头，拍一帧 JPEG，拍完立刻释放。

What you get

你得到什么

Free Cursor plugin — skills, rules, and a snap command so the agent knows when to take one frame and how the image returns to the conversation. No .exe, no tray, no always-on camera process in this layer.

In-chat photo button (MCP Apps). When the MCP App UI is available in the conversation, you can tap a take one photo control in chat — same on-demand one JPEG, then the camera is released. · 对话内可点「拍一张」按钮（MCP Apps）。

Local MCP (webcam_mcp) — Cursor starts it over stdio via uv. take_photo opens camera index 0, returns one JPEG into the chat, and releases the device before the tool returns.

Pro (later) — packaged installer / system tray. Not for sale on this page yet.

How a shot works

一次抓拍怎么走

  1. Install the free plugin from Cursor Marketplace (after listing) or clone into ~/.cursor/plugins/local/webcam-bridge.
  2. Install uv so Cursor can fetch and run webcam_mcp from Git.
  3. Allow camera access if the OS asks.
  4. Ask for one photo, or run the snap command. First start may need network for uv to pull the server.
The camera stays closed until take_photo runs. This bridge’s playbook uses still frames only — not continuous video. (webcam_mcp also has record_video; the free plugin does not use it.)
