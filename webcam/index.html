Webcam Bridge · Free

One photo in the chat. The camera closes after the shot.

The free plugin tells the agent when to take a frame. Capture itself is a local MCP server, webcam_mcp: it opens camera index 0, returns one JPEG into the current chat, and releases the device before the tool returns.

What you get

  • One JPEG, then release

    take_photo opens the camera, returns one JPEG, and releases it before the tool returns. The camera stays closed until that call. This plugin’s playbook is still frames only.

  • Snap command or an in-chat button

    Ask for a photo, or run snap. When MCP Apps is available, a take one photo control in the chat does the same shot.

  • Local server, started by uv

    Cursor starts webcam_mcp over stdio via uv. No .exe and no tray in the free layer.

  • Pro installer is not for sale

    A packaged installer and system tray are planned later. The button on this page is a placeholder, not an offer. record_video exists on webcam_mcp; the free plugin does not use it.

How a shot works

  1. Install the free plugin from Cursor Marketplace (after listing) or clone into ~/.cursor/plugins/local/webcam-bridge.
  2. Install uv so Cursor can fetch and run webcam_mcp from Git.
  3. Allow camera access if the OS asks.
  4. Ask for one photo, or run the snap command. First start may need network for uv to pull the server.
The camera stays closed until take_photo runs. This bridge’s playbook uses still frames only — not continuous video. (webcam_mcp also has record_video; the free plugin does not use it.)
