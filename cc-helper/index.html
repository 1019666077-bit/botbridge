What it does

  • Dispatch into a local inbox

    The free plugin teaches the bot how to write one job, poll progress, and stop a run. The Helper owns inbox\, runs Claude Code, and shows progress in the tray panel. Free is one task at a time.

  • Approve or cancel a blocker from your phone

    Pro opens a one-tap page when a pay or submit step is waiting. Continue approves that task once; Cancel stops it. The link lasts 24 hours and is single-use. Free leaves you at the PC to continue.

  • Bark screenshot push

    Alerts go through Bark, or a webhook you configure. Free is a text push. Pro can include a screenshot of the step that is waiting.

  • Budget caps, stall stop, parallel jobs

    Pro enforces a hard token budget, stops a run that stalls, and runs up to 3 jobs in parallel with auto-retry. Free keeps soft guidance only. One Pro code covers up to 2 machines.

Same Claude Code CLI, your keys. This is not a Claude Code GUI, fork, or official extension, and it is not Anthropic Remote Control. Remote Control needs an Anthropic account and does not cover Windows the same way. CC Helper is not affiliated with Anthropic or Cursor.

Two layers

两层：市场里的免费插件，加上本机 Helper。

Free marketplace plugin — skills and soft hooks that teach the bot how to dispatch, poll progress, and stop a job. Soft tips only (no hard shell block in the plugin itself). Cursor Marketplace: submitted, not listed yet. The plugin does not include the tray, Bark or webhook notify, or budget caps.

Desktop Helper (Windows) — tray / daemon that owns the inbox, runs Claude Code, shows the panel, sends Bark or webhook alerts, and enforces Free vs Pro limits. Without it, the plugin is only the playbook.

How it fits together

  1. Install the free plugin in Cursor or Grok Bot — it gives the bot the dispatch playbook.
  2. Install the Windows Helper (email for the installer; after Pro, claim your key) and keep the tray running.
  3. Ask the bot to dispatch: it writes a job into inbox\; Claude Code runs on your PC with your API key (DeepSeek or others).
  4. Watch the panel — or walk away. Pro sends a phone link when a pay or submit step needs approve/cancel, and can attach a screenshot via Bark; budget caps and stall auto-stop keep spend in check; up to 3 parallel jobs with auto-retry.
