Two layers

两层：市场薄插件 + 本机 Helper

Free marketplace plugin — skills, rules, and soft hooks. It teaches the bot how to write inbox JSON, poll status, and stop a job. Soft tips only: it does not hard-block risky shells. Submitted for review on Cursor Marketplace (not listed yet) · 已提交审核，尚未上架. Install from Marketplace / Connect Apps when it goes live, or clone into ~/.cursor/plugins/local/cc-helper.

Desktop Helper (Windows) — tray / daemon with a progress panel. This is what actually runs and watches Claude Code in realtime. Without it, the plugin is only the playbook layer.

Free vs Pro

Free 派活闭环 · Pro 预算硬顶、超时判死、手机通知

Both tiers let the bot hand real work to Claude Code on your PC. How it fits together

  1. Install the free plugin in Cursor or Grok Bot.
  2. Install the Windows Helper (request the installer by email) and keep the tray running.
  3. Ask the bot to dispatch with the cc-helper-dispatch skill.
  4. Watch progress locally; Pro users get hard caps and Bark/webhook when something blocks.
