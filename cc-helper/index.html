What it is — and what it isn’t

是什么、不是什么

Bot Bridge CC Helper is a dispatch bridge. A remote bot — Cursor or Grok Bot — writes a task into a local inbox on your machine, the desktop Helper runs Claude Code with it, and status and progress stream back into a tray panel so you can watch, step in, or walk away. The bot drives; your PC does the work.

It is not a Claude Code GUI, a Claude Code fork, or an official extension. It does not replace the Claude Code CLI or your editor extension, and it is not made by, endorsed by, or affiliated with Anthropic or Cursor. It wraps the CLI you already have: same Claude Code, driven by your bot instead of your keyboard.

Two layers

两层：市场薄插件 + 本机 Helper

Free marketplace plugin — skills, rules, and soft hooks. It teaches the bot the dispatch playbook: how to write inbox JSON, poll progress, and stop a job. Soft tips only: it does not hard-block risky shells. Submitted for review on Cursor Marketplace (not listed yet) · 已提交审核，尚未上架. Install from Marketplace / Connect Apps when it goes live, or clone into ~/.cursor/plugins/local/cc-helper.

Desktop Helper (Windows) — tray / daemon that owns the inbox and actually runs and watches Claude Code: it picks up dispatched jobs, streams progress, and enforces the Pro limits below. Without it, the plugin is only the playbook layer.

Free vs Pro

Free 派活闭环 · Pro 预算硬顶、超时判死、手机推送

How it fits together

派活闭环

  1. Install the free plugin in Cursor or Grok Bot — it gives the bot the dispatch playbook.
  2. Install the Windows Helper (request the installer by email; after buying Pro, claim your key) and keep the tray running. This is the part that actually runs Claude Code.
  3. Ask the bot to dispatch with the cc-helper-dispatch skill: it writes one job JSON into inbox\.
  4. Watch progress in the tray — or walk away. Pro hard-stops over-budget or stalled jobs and pushes a Bark/webhook alert when something blocks.
