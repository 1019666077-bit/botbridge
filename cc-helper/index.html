What it is — and what it isn’t

是什么、不是什么

A dispatch bridge for bots → local Claude Code. Your bot writes a job into a local inbox; the Windows Helper runs Claude Code, streams progress, and can return structured results to the bot. With Pro you can approve or cancel paywalls / submit steps from your phone in one tap — with an optional screenshot — instead of babysitting the PC.

Not a Claude Code GUI, fork, or official extension. Not Anthropic Remote Control. Not affiliated with Anthropic or Cursor. Same Claude Code CLI you already run, driven by your bot and your keys (DeepSeek, Anthropic, or others your setup supports).

Two layers

两层：市场薄插件 + 本机 Helper

Free marketplace plugin — skills and soft hooks that teach the bot how to dispatch, poll progress, and stop a job. Soft tips only (no hard shell block in the plugin itself). Cursor Marketplace: submitted, not listed yet.

Desktop Helper (Windows) — tray / daemon that owns the inbox, runs Claude Code, shows the panel, pushes text alerts, and enforces Free vs Pro limits. Without it, the plugin is only the playbook.

How it fits together

派活闭环

  1. Install the free plugin in Cursor or Grok Bot — it gives the bot the dispatch playbook.
  2. Install the Windows Helper (email for the installer; after Pro, claim your key) and keep the tray running.
  3. Ask the bot to dispatch: it writes a job into inbox\; Claude Code runs on your PC with your API key (DeepSeek or others).
  4. Watch the panel — or walk away. Pro sends a phone link when something needs approve/cancel (optional screenshot); budget caps and stall auto-stop keep spend in check; up to 3 parallel jobs with auto-retry.
