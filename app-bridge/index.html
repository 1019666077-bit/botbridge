App Bridge

Let Cursor see what’s on your Windows desktop — list open windows, read on-screen UI text, and take a screenshot — through a free thin plugin and a local MCP server. No always-on tray exe in the free layer.

免费薄插件 + 本机 MCP：列出窗口、读界面文字、截图。点击/输入等留给 Pro 占位。

For Cursor and Grok Bot (Agent / Bot plugins). · 面向 Cursor 与 Grok Bot（Agent / Bot 插件）。

Status. Product page staking — not listed on Cursor Marketplace yet · 尚未上架. Free layer is MIT.

How it fits

  1. Clone app-bridge-plugin (with submodules) into ~/.cursor/plugins/local/app-bridge, or install from Marketplace when listed.
  2. Install uv so Cursor can run the forked Windows-MCP server locally.
  3. Ask to list windows, read UI text, or screenshot — or run /list-windows.
